# L4D2 si_hud 计分体系（2026-08-02，v1.7.51-63）

## 击杀分（v1.7.52，用户设计）

**击杀分 = 基础分 × 爆头倍率 × 满血倍率**（连乘后统一 ceil）

- 基础分 = 特感实际最大血量 × 25%（`si_hud_bf_points_base_pct`，实时读 m_iMaxHealth，服务器调血后自动跟随）；Tank 1500 / Witch 500 固定（大头在伤害分）
- 爆头 ×1.5（`si_hud_bf_headshot_mult`）、满血 ×1.25（`si_hud_bf_fullhp_mult`，与爆头连乘）
- 近战加成取消（近战优势已有伤害分倍率）
- 例：Witch 满血爆头 500×1.5×1.25 = 937.5 → **938**；Tank 爆头 2250

## 伤害分（定死公式，用户明确不参与连杀）

**伤害分 = 实际造成血量 × 武器倍率 × 0.1**（`si_hud_bf_damage_coeff`，10 血 = 1 分）

- 武器倍率：AR 1.0 / SMG 1.5 / 木喷+铁喷 1.5（v1.7.52 修 chrome 原误走 other）/ 马格南 1.75 / **手枪+双枪 1.75**（v1.7.52 新 cvar `si_hud_bf_damage_mult_pistol`）/ 近战 1.75 / 连喷+SPAS 0.75 / 狙 0.75 / other 1.0
- 设计定论（用户拍板）：伤害分已有单独奖励机制（即时入账钱包+总分），**连杀是连杀**——打 Tank 血没杀死不推动 award，边界场景作废

## 连杀奖励（v1.7.53 电费阶梯 + v1.7.60 门槛 + v1.7.63 手配倍率）

**加权人头 = 特感×6 + 小僵尸×1**（救援不占人头）

**奖励 = Σ(各段实际人头 × 1.3 × 该段倍率)**，每段 ceil；按结算瞬间实际击杀数分段累计，无跳档悬崖（例：hw=24 → 333、hw=26 → 370、hw=45 → 748）

- 段边界 `si_hud_streak_hw_l1..l6`：20/40/55/70/85/100（不变）
- **v1.7.63 倍率改每档手配（用户拍板，加速曲线）**：`si_hud_streak_bonus_mult_l1..l6` = 10/14/19/25/32/40，删 `_mult_step` 1.5 线性步进 → 满档奖励 260/624/995/1483/2107/2887，增量 +260/+364/+371/+488/+624/+780（旧步进各段增量近似持平 +300，杀 20 头和杀 100 头每档拿的钱差不多，高段无激励）
- **l1 是门槛（v1.7.54 实测修正 + v1.7.60 升级）**：hw < 20 → 奖励 0 且**整个结算静默**——窗口关闭只重置连杀状态，不弹结算卡、不播奖励音效（v1.7.60 前结算卡只看 score>0：3 特感 hw=18 弹 +295 卡误导、单杀女巫 hw=6 也弹"连杀结算"）
- 旧 cvar `si_hud_streak_bonus_l2/l4/l6`（30/50/100）已废弃；`_mult_step` 引擎残留无害（重启消失）
