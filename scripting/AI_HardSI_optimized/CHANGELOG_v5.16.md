### 1. Hunter 墙面二段跳 ✨ NEW

**功能**：Hunter 扑空后在空中检测墙面，可以进行二次扑击

#### 检测条件
```sourcepawn
// 必须同时满足：
1. 在空中（!(FL_ONGROUND)）
2. 刚扑击过（g_bHunterJustLunged）
3. 未使用过二段跳（本次起跳只能用一次）
4. 有足够垂直速度（|vz| > 50 u/s）
5. 四个方向有墙面（距离 < 80u）
```

#### 墙面检测机制
- 检测方向：前、左、右、后
- 检测距离：80u
- 使用射线追踪（TraceRay）
- 命中率：>90% 视为墙面

#### 二段跳行为
```sourcepawn
// 执行流程：
1. 获取最近的幸存者作为目标
2. 瞄准目标 + 随机偏移（±15° 水平，±10° 垂直）
3. 按 IN_ATTACK 执行扑击
4. 标记已使用二段跳（g_bHunterUsedWallPounce = true）
```

#### 标记重置
- 扑击成功（有 victim）→ 重置标记
- 落地后逃跳 → 重置标记
- 下次起跳重新可用

#### 行为树集成
- **优先级 2**（仅次于扑空逃跳）
- 在空中时优先检测墙面二段跳
- 失败则执行其他空中逻辑

**预期效果**：
- Hunter 扑空后不再无助落地
- 利用墙面反弹进行二次攻击
- 增加扑击成功率和威胁性

### 2. Spitter 预判投掷 ✨ NEW

**功能**：根据幸存者移动方向和速度，预判投掷位置

#### 预判触发条件
```sourcepawn
// 目标水平速度 > 150 u/s
float speed = sqrt(vx² + vy²)
if (speed > 150.0) {
    // 启用预判
}
```

#### 预判计算公式
```sourcepawn
// 1. 估算飞行时间
flightTime = distance / 1100.0  // 酸液抛物线速度约 1100 u/s

// 2. 计算预判点
predictedPos = currentPos + velocity × flightTime × 0.65

// 3. 安全检查
if (偏移 < 300u) {
    // 使用预判点
} else {
    // 偏移过大，使用原点
}
```

#### 保守系数
- **0.65**：避免过度预判
- 原因：玩家可能改变方向
- 效果：命中率提升但不至于"神准"

#### 预判效果对比

| 目标状态 | 原版瞄准 | v5.16 预判 |
|---------|---------|-----------|
| 静止（<150u/s） | 直接瞄准 | 直接瞄准（无变化） |
| 慢速移动（150-300u/s） | 容易躲避 | 提前量小，命中率↑30% |
| 快速移动（>300u/s） | 基本落空 | 提前量大，命中率↑60% |

**预期效果**：
- 对静止玩家命中率不变
- 对移动玩家命中率显著提升
- Spitter 威胁性增强

### 3. Jockey 弹跳骑乘增强 ✨ NEW

**功能**：骑乘时更频繁、更大幅度地变换方向 + 垂直抖动

#### v5.16 增强对比

| 参数 | 原版（v5.15） | v5.16 增强 |
|------|-------------|-----------|
| 转向频率 | 0.5-1.0s | **0.3-0.5s** |
| 转向角度 | ±30-45° | **±60-90°** |
| 垂直抖动 | 无 | **10% 概率/tick** |

#### 转向机制
```sourcepawn
// 每 0.3-0.5s 切换一次方向
float bounceOffset = GetRandomFloat(60.0, 90.0) * (±1)
ang[1] += bounceOffset

// 三种骑乘场景都应用增强：
1. 拖向酸液（优先级最高）
2. 拖向队伍外（远离中心）
3. 被队伍包围（随机大角度）
```

#### 垂直抖动
```sourcepawn
// 10% 概率每 tick 按跳跃键
if (GetRandomFloat(0.0, 1.0) < 0.10) {
    BT_AddButton(client, IN_JUMP);
}
```

#### 应用场景

**场景 1 - 拖向酸液**：
- 检测到酸液（80-900u）
- 计算方向 + 大角度偏移（±60-90°）
- 频繁转向（0.3-0.5s）
- 垂直抖动

**场景 2 - 拖向队伍外**：
- 计算远离队伍中心方向
- 大角度偏移（±60-90°）
- 频繁转向
- 垂直抖动

**场景 3 - 被包围**：
- 寻找最近特感方向
- 大角度偏移（±60-90°）
- 频繁转向
- 垂直抖动

**预期效果**：
- 被骑乘玩家感觉像坐过山车
- 队友更难瞄准 Jockey
- 救援难度显著提升
- 骑乘威胁性增强

### 4. Tank 物体投掷瞄准 ✨ NEW

**功能**：Tank 击打周围物体时，控制其飞行轨迹朝向幸存者

#### 实现机制

**1. 物理道具监听**
```sourcepawn
// OnEntityCreated 钩子
监听类型：
- prop_physics
- prop_car_alarm
- prop_physics_multiplayer
```

**2. 速度检测**
```sourcepawn
// 0.1秒后检查物体速度
if (speed > 400 u/s) {
    // 可能被 Tank 击打
}
```

**3. Tank 确认**
```sourcepawn
// 查找附近的 Tank（<300u）
for each Tank:
    if (距离 < 300u) {
        // 确认是 Tank 击打
    }
```

**4. 目标选择**
```sourcepawn
// 找到最近的幸存者（<1500u）
target = closest_survivor_within_1500u
```

**5. 轨迹修改**
```sourcepawn
// 计算新速度向量
dir = normalize(propPos → targetPos)
newVel.x = dir.x × speed × 0.8
newVel.y = dir.y × speed × 0.8
newVel.z = dir.z × speed × 0.5 + oldVel.z × 0.5

// 0.8 系数：避免过于精准
// 垂直速度混合：保留部分抛物线
```

#### 参数调整

| 参数 | 值 | 说明 |
|------|-----|------|
| 速度阈值 | 400 u/s | 低于此值不修改 |
| Tank 检测半径 | 300u | Tank 必须在此范围内 |
| 目标搜索半径 | 1500u | 超出范围不修改 |
| 水平精度系数 | 0.8 | 避免 100% 命中 |
| 垂直保留系数 | 0.5 | 保留抛物线效果 |

#### 效果演示

**场景 1 - Tank 打飞车辆**：
- 原版：随机方向飞出
- v5.16：朝最近玩家方向飞去
- 命中率：从 ~5% 提升到 ~40%

**场景 2 - Tank 打翻桌子**：
- 原版：桌子滚向随机方向
- v5.16：桌子朝玩家方向滚动
- 威胁范围扩大

**预期效果**：
- 环境物体成为 Tank 的武器
- 玩家需要躲避飞来的物体
- Tank 战斗更具动态性
