## 🔄 重载方式

### 方式 1：游戏内控制台（推荐）

如果你有管理员权限，在游戏内按 `~` 打开控制台，输入：

```
sm plugins reload AI_HardSI
```

### 方式 2：通过 Admin Panel

1. 访问 Admin Panel
2. 找到 "Server Management" 或 "Plugins" 部分
3. 找到 AI_HardSI 插件
4. 点击 "Reload" 按钮

### 方式 3：重启服务器（最保险）

```bash
cd /opt/gameservers/l4d2
docker-compose restart l4d2-server
```

**注意**：重启会踢出所有玩家，建议在服务器空闲时执行。

### 方式 4：等待自动生效

- 插件文件已更新（75K，最新版本）
- 下次地图切换时会自动重新加载插件
- 或者等待服务器自然重启

## ✅ 验证插件版本

重载后，在控制台输入：

```
sm plugins list
```

查找 AI_HardSI，确认状态为 "Running"。
