## 🎯 核心改进

### 1. Hunter 骚扰模式升级（bt_hunter.inc）

**原问题**：完全不扑击显得太呆板  
**改进方案**：保持骚扰距离，但允许机会性扑击

#### 新增逻辑
```sourcepawn
// 机会性扑击条件：
// 1. 冷却：8秒（比正常模式少 40% 攻击频率）
// 2. 距离：400-800u
// 3. 满足以下任一条件：
//    - 玩家落单（距离队友 >500u）
//    - 玩家背对（视角差 >90°）
```

#### 行为流程
1. **检测机会**：每 8 秒检查一次玩家状态
2. **准备扑击**：满足条件 + 有 LOS → 先蹲下
3. **执行扑击**：蹲下完成 → 立即扑击
4. **恢复骚扰**：扑击后继续保持距离游走

**预期效果**：Hunter 在骚扰期不会一直晃悠，而是伺机偷袭落单/分神的玩家

---

### 2. Charger 骚扰模式升级（bt_charger.inc）

**原问题**：只威慑不冲锋显得太呆板  
**改进方案**：保持威慑距离，但允许短距离冲锋

#### 新增逻辑
```sourcepawn
// 机会性冲锋条件：
// 1. 冷却：18秒（比正常 12 秒少 50% 攻击频率）
// 2. 距离：300-600u（限制冲锋距离）
// 3. 满足以下任一条件：
//    - 玩家落单（距离队友 >500u）
//    - 玩家接近边缘（前方 200u 内有悬崖）
```

#### 悬崖检测机制
- 读取玩家朝向
- 向前方 200u 投射射线
- 检测地面高度差（>300u 视为悬崖）
- 检测到悬崖 → 触发短距离冲锋

**预期效果**：Charger 在骚扰期会抓住玩家失位/边缘机会进行快速冲锋

---

### 3. Jockey 骚扰模式新增（bt_jockey.inc）✨ NEW

**功能**：快速骑乘但不往危险区骑，3-5 秒后主动跳下

#### 核心行为：`JockeyAct_HarasserRide`

##### 距离控制（骑乘前）
```
> 700u：接近（±25° 偏移）
< 400u：后退
400-700u：横移 + 伺机骑乘
```

##### 机会性骑乘
**条件**：
- 冷却：10 秒
- 距离：≤450u
- 在地面上
- **安全检测通过**

##### 安全检测机制
**悬崖检测**：
- 检查玩家前方 100u、200u、300u 三个点
- 每个点向下投射射线 300u
- 任一点无地面（或高度差 >80%）→ 不安全

**酸液检测**：
- 检查玩家周围 200u 内是否有 Spitter 酸液
- 有酸液 → 不安全

##### 快速骑乘逻辑
**骑上后**：
- 记录骑乘开始时间（`_jockey_harass_ride_start`）
- 随机生成跳下时间：3-5 秒
- 骑乘期间：小幅度移动（±15° 随机角度）
- **不往危险区带**（不执行完整 steering）

**主动跳下**：
- 达到时间 → 按 `IN_JUMP` 跳下
- 清除骑乘标记
- 恢复骚扰模式

#### 行为树集成
```
Root Selector 优先级 2（仅次于正常骑乘）：
├─ CND_IsHarasser（是骚扰者）
├─ Inverter(CND_InitiatorEngaged)（发起者尚未成功）
└─ Sequence:
   ├─ ACT_AcquireClosestTarget
   └─ JockeyAct_HarasserRide
```

**预期效果**：
- Jockey 在骚扰期会进行快速骑乘骚扰
- 不会把人往悬崖/酸液带（安全环境才骑）
- 3-5 秒快速跳下，不会深度控制

## 🎮 战斗流程演示

### 阶段 1 - 骚扰期（发起者尚未成功）

**Boomer**：慢慢接近玩家  
**Hunter**：600-1000u 距离横移游走  
　├─ 玩家落单 → 机会性扑击（8s冷却）  
　└─ 玩家背对 → 机会性扑击  
**Charger**：400-800u 距离横移威慑  
　├─ 玩家落单 → 短距离冲锋（18s冷却）  
　└─ 玩家边缘 → 短距离冲锋  
**Jockey**：400-700u 距离横移伺机  
　└─ 安全环境 → 快速骑乘 3-5s 跳下（10s冷却）

**玩家感受**：压力不大，但需要保持队形和警觉

### 阶段 2 - 爆发期（Boomer 呕吐成功）

**所有骚扰者**：立即切换全力进攻模式  
├─ Hunter：立即扑击（无距离限制）  
├─ Charger：立即冲锋（无距离限制）  
└─ Jockey：立即骑乘（完整 steering，拖向队伍外）

**玩家感受**：屏幕被胆汁覆盖 + 多重控制 → 高压崩溃

## 🔧 技术细节

### 变量命名修复
**问题**：`forward` 是 SourcePawn 关键字，不能作为变量名  
**修复**：`float forward[3]` → `float forwardVec[3]`  
**影响文件**：`bt_charger.inc`、`bt_jockey.inc`

### 黑板变量新增

#### Hunter
- `_harass_last_pounce`：上次机会性扑击时间（8s冷却）

#### Charger
- `_harass_last_charge`：上次机会性冲锋时间（18s冷却）

#### Jockey
- `_jockey_harass_strafe_left`：横移方向
- `_jockey_harass_strafe_next`：下次切换横移时间
- `_jockey_harass_last_leap`：上次骑乘时间（10s冷却）
- `_jockey_harass_ride_start`：骑乘开始时间（标记快速骑乘模式）
