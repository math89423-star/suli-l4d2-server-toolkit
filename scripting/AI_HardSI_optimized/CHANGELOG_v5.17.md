## 🎯 Phase 3 功能实现

### Hunter 逃跑跳转扑击跳（Flee to Pounce）✨ NEW

**来源**：Improved Hunter AI (Steam Workshop #3140922442)

**功能描述**：
- Hunter 扑空后的逃跑跳（EscapeJump）自动转为扑击跳
- 避免浪费逃跑的跳跃高度
- 空中可能再次命中目标

#### 实现方式

**原版逃跑跳**：
```sourcepawn
BT_AddButton(client, IN_JUMP);  // 只按跳跃键
```

**v5.17 改进**：
```sourcepawn
BT_AddButton(client, IN_JUMP);
BT_AddButton(client, IN_ATTACK);  // 同时按扑击键
```

#### 效果对比

| 场景 | 原版（v5.16） | v5.17 |
|------|-------------|-------|
| 扑击落空 | 逃跑跳（单纯逃离） | 逃跑跳 + 扑击 |
| 空中高度 | 浪费 | 可能命中目标 |
| 威胁性 | 低（纯防御） | 高（攻防兼备） |

#### 与墙面二段跳配合

**连招流程**：
1. **扑击落空** → 触发 EscapeJump
2. **逃跑跳 + 扑击** → 可能空中命中
3. **如果再次落空** + 贴墙 → 墙面二段跳
4. **墙面反弹** → 第三次扑击机会

**理论最大连续攻击次数**：3 次
- 第 1 次：正常扑击（落空）
- 第 2 次：逃跑跳转扑击（落空）
- 第 3 次：墙面二段跳（最后机会）
